# LLM Output Repair

Extract and repair JSON and YAML generated by language models, without another inference call.

## Status

Initial extraction of the existing Backplane parsing utilities. This is an experimental,
**tolerant** repair library, not a lossless or security-validated parser. It can change
values or structure (for example, unwrapping embedded JSON, removing ellipses or
repairing YAML indentation). Always validate results against your application's
schema and domain invariants. Do not use it for untrusted input without independent
resource limits and review. It does not yet guarantee ambiguity rejection, bounded
resource use or semantic preservation.

## Install

```bash
pip install .
```

## Usage

```python
from llm_output_repair import repair_json, repair_yaml, YamlNormalizer

obj = repair_json('Here is the result: {"name": "example"}')
doc = repair_yaml("items:\n- name: example\n")
```

Legacy-compatible APIs: `extract_json_new` returns JSON text,
`extract_yaml_new` returns a parsed value, and `dump_yaml` serializes a value.
`YamlNormalizer` exposes the inherited text normalization pipeline.
Transport helpers are in `llm_output_repair.yaml_transport`.

## Scope

The library contains format repair and normalization only. Domain-specific parsers,
candidate ranking, LLM clients, orchestration, private prompts and crash logs are
not included. The extracted algorithms are preserved; the Backplane logging
dependency is replaced by standard Python logging. Tests use generic examples.
